# Phantom Lancer Farm — адаптация morphling_farm.lua

Основной файл `phantom_lancer_farm.lua` переделан непосредственно из предоставленного пользователем `examples/morphling_farm.lua`. Авторство встроенной библиотеки qLocalization сохранено.

Сохранены исходные меню и локализация, панель выбора кемпов, выбор лагерей, обработка пустых лагерей, отступление по HP и видимым врагам, логика предметов и покупка/использование Clarity. Предыдущая самостоятельная реализация заменена; она доступна в истории Git.

## Изменения для ПЛ

- Проверка героя заменена на `npc_dota_hero_phantom_lancer`.
- Вместо дальних атак с кайтингом используется ближняя атака без отбегания после каждого удара.
- Добавлено управление своими подконтрольными иллюзиями Phantom Lancer: атака той же пачки, следование при переходе и отходе.
- Waveform, Adaptive Strike и Morph Strength удалены.
- Spirit Lance для фарма и Doppelganger для побега — отдельные настройки, обе по умолчанию выключены.
- Ограничение по проценту маны удалено; проверяется наличие маны на применение способности.
- Отдельное пространство настроек `phantom_lancer_farm_v2`.

## Запуск

1. Скачайте `phantom_lancer_farm.lua` и замените им предыдущую версию в загрузчике Umbrella. Оставьте подключённой одну версию скрипта.
2. Перезагрузите скрипты, выберите Phantom Lancer.
3. Настройки находятся в **Heroes → Hero List → Phantom Lancer → Main Settings**. Если раздела героя нет — в **Scripts → Phantom Lancer Farm → Settings**.
4. Включите скрипт и назначьте «Переключатель фарма». Первое нажатие запускает фарм, второе останавливает. Как в исходнике, при наличии основного переключателя героя он тоже должен быть включён.
5. Клавиша «Панель выбора кемпов» открывает исходную панель выбора лагерей.

Необязательный фон карты использует прежний путь `images/morphling_farm_map.png`. Если изображения нет, точки лагерей остаются доступны на панели без фона.

## Исходное поведение

Покупка Clarity оставлена как в присланном файле: одна в игровую минуту, использование между боями с нейтралами. Healing Salve, обмен с ранцем и новая логика курьера из предыдущей самостоятельной версии сюда не перенесены. Маршрутизация сохранена из исходника, включая приоритет ближайшего известного занятого лагеря над пустым.

## Проверка

```sh
python -m pip install -r requirements-dev.txt
python tests/test_farm.py
```

Проверены загрузка, меню, фильтр героя, исходный цикл выбора/пропуска пустого лагеря, ближние атаки, атаки иллюзий, отсутствие дальнего кайтинга и ползунка маны, имена API, применение Spirit Lance и Doppelganger. Используется имитация API; в Dota/Umbrella скрипт ещё не проверен.
