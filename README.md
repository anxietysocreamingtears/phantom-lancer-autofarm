# Phantom Lancer AutoFarm — Umbrella Lua

Автофарм леса для Phantom Lancer в Dota 2 на API Umbrella Lua.

## Возможности

- Выбор ближайшего лагеря с подтверждёнными живыми видимыми нейтралами в пределах радиуса от точки включения. Каждый крип относится только к одному лагерю.
- Управление героем и его собственными иллюзиями: совместный фарм одного лагеря.
- Spirit Lance выключен по умолчанию. При явном включении используется только по цели с HP от 300, если рядом с героем менее двух управляемых иллюзий и герой ещё не атакует. Процентного ограничения маны нет: достаточно маны на само применение. Другие способности автоматически не используются.
- Отход к союзному фонтану при низком здоровье или появлении видимого врага рядом.
- Возобновление после восстановления здоровья до 90%.
- Пропуск пустых лагерей до следующей минуты.
- Древние нейтралы отключены по умолчанию.

## Установка

1. Скачайте `phantom_lancer_farm.lua` и подключите в Lua-загрузчике Umbrella.
2. Выберите Phantom Lancer.
3. Откройте **Scripts → PL Farm → Settings → Автофарм**.
4. Включите скрипт, назначьте клавишу «Автофарм» и выберите для бинда режим переключения.
5. Активируйте автофарм в центре желаемого маршрута. Эта позиция станет точкой отсчёта радиуса.
6. Для остановки выключите бинд или основной переключатель.

## Проверка и ограничения

Проверены синтаксис Lua, наличие используемых функций в предоставленной документации и сценарии на имитации API: выключенный режим, атака нейтралов, отход при низком HP, восстановление, отход от врага, сброс состояния.

В реальном матче скрипт не проверен. Совместимость зависит от версии Umbrella и Dota 2. Проверка опасности учитывает только видимых героев противника. Маршрут выбирается по расстоянию, без оценки безопасности пути. Если сущность союзного фонтана недоступна, команда отхода не отправляется. Нет стакинга, фарма линий и использования Manta.

Исходные примеры сохранены без изменений; их авторство принадлежит соответствующим авторам.

## Flask / Clarity

Автовосстановление включено по умолчанию и работает при активном автофарме.

- При здоровье строго ниже 50% покупается Healing Salve (`item_flask`); при мане строго ниже 50% — Clarity. При нехватке обоих ресурсов покупаются оба типа.
- Учитываются имеющиеся расходники в инвентаре, ранце, тайнике и на личном курьере, активный эффект, золото и запас магазина. Между попытками покупки одного типа — минимум 30 секунд.
- Предметы из тайника запрашиваются через способность доставки личного курьера. Покупка и доставка зависят от правил магазина, свободного места и состояния курьера.
- Перед применением герой выходит из лагеря; расходники используются на себя вне радиуса 850 от видимых нейтралов и вне радиуса опасности от видимых героев.
- Если расходник в ранце, он перемещается в свободный основной слот; при полном инвентаре временно вытесняется самый дешёвый подходящий предмет. После ожидания минимум 6,2 секунды дополнительно проверяется готовность предмета.
- После применения вытесненный предмет возвращается в исходный слот. Если игрок вручную изменил задействованные слоты, скрипт прекращает восстановление, чтобы не перезаписать эти изменения. При выключении автофарма незавершённый обмен также восстанавливается, пока герой жив.
- Во время Flask/Clarity герой приостанавливает фарм и трату маны, чтобы дать восстановлению закончиться. Видимые враги имеют приоритет: герой отходит.

Цены для предварительной проверки: Salve — 110, Clarity — 50 золота; ID предметов — 39 и 38. Если патч меняет их, обновите таблицу `supplies`. Скрытые враги и летящие атаки не учитываются. Перемещение пассивного предмета временно убирает его бонусы; после возврата действует обычная задержка активации Dota.

## Проверки

```sh
python -m pip install -r requirements-dev.txt
python tests/test_farm.py
```

Дополнительно проверяются порог 50%, независимая покупка расходников, защита от повторного применения при активном эффекте, перенос из ранца, задержка активации и возврат исходного предмета. Проверки используют имитацию API; доставка курьером и реальные игровые задержки требуют проверки в матче.

## Выбор лагерей

Подтверждённые пустые лагеря не являются целями маршрута. После исчезновения последнего видимого живого крипа герой сразу выбирает другую подтверждённую пачку; предыдущий лагерь пропускается до следующего времени спавна по часам Dota. Возврат после спавна возможен только при наличии живых видимых крипов. Если видимых пачек нет, герой проверяет ещё не посещённые лагеря, чтобы получить обзор. После проверки всех доступных лагерей герой и иллюзии ждут вне прямоугольников спавна. Поиск точки ожидания геометрический, без проверки проходимости рельефа.

Лагеря в тумане войны не считаются подтверждёнными: скрипт подходит к ним для получения обзора. Опция «Проверять лагеря без обзора» включена по умолчанию; при её выключении фармятся только уже видимые пачки. Пустой лагерь проверяется 1,5 секунды после прибытия и пропускается до следующего спавна; на попытку подхода даётся 25 секунд. Проверки на имитации API покрывают соседние лагеря, смерть последнего крипа, переход к следующему, ожидание, новый спавн и отсутствие обзора.

## Если герой стоит

Включите основной переключатель и активируйте назначенный бинд «Автофарм» в режиме переключения. Настройка «Причина ожидания в консоли» выводит сообщения `[PL Farm]` при смене состояния: выключенный бинд, отход, расходники, проверка лагеря или ожидание спавна. Отсутствие видимых пачек само по себе больше не останавливает маршрут: включённая по умолчанию проверка лагерей получает обзор.

## Восстановление маны без фонтана

Низкая мана не отправляет героя на фонтан. Для Clarity (и Salve при некритическом HP) герой выбирает ближайшую подходящую точку на расстоянии 900–1800 от текущей позиции, вне радиуса 900 от видимых нейтралов и вне опасности видимых героев. Когда дистанция до крипов достаточна, движение останавливается и используется расходник. При активном эффекте расходника отход также локальный. Геометрический выбор точки не гарантирует проходимость пути. Отход на фонтан сохраняется при критически низком здоровье и видимом противнике.
