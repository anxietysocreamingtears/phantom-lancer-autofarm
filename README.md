# Phantom Lancer AutoFarm — Umbrella Lua

Автофарм леса для Phantom Lancer в Dota 2 на API Umbrella Lua.

## Возможности

- Выбор ближайшего лагеря в пределах радиуса от точки включения.
- Управление героем и его собственными иллюзиями: совместный фарм одного лагеря.
- Spirit Lance с учётом маны, дальности и готовности способности.
- Отход к союзному фонтану при низком здоровье или появлении видимого врага рядом.
- Возобновление после восстановления здоровья до 90%.
- Пропуск пустых лагерей до следующей минуты.
- Древние нейтралы отключены по умолчанию.

## Установка

1. Скачайте `phantom_lancer_farm.lua` и подключите в Lua-загрузчике Umbrella.
2. Выберите Phantom Lancer.
3. Откройте **Scripts → PL Farm → Settings → Автофарм**.
4. Включите скрипт, назначьте клавишу «Автофарм» и выберите для бинда режим переключения.
5. Активируйте автофарм в центре желаемого маршрута. Эта позиция станет точкой отсчёта радиуса.
6. Для остановки выключите бинд или основной переключатель.

## Настройки по умолчанию

| Настройка | Значение |
|---|---|
| Управление иллюзиями | Включено |
| Spirit Lance | Включён |
| Минимум маны | 40% |
| Отход при здоровье | 35% |
| Возобновление после лечения | 90% |
| Радиус опасности | 1400 |
| Радиус маршрута | 5000 |
| Древние | Выключены |

- `references/umbrella-lua.zip` — предоставленный пользователем архив документации API.

## Проверка и ограничения

Проверены синтаксис Lua, наличие используемых функций в предоставленной документации и сценарии на имитации API: выключенный режим, атака нейтралов, отход при низком HP, восстановление, отход от врага, сброс состояния.

В реальном матче скрипт не проверен. Совместимость зависит от версии Umbrella и Dota 2. Проверка опасности учитывает только видимых героев противника. Маршрут выбирается по расстоянию, без оценки безопасности пути. Если сущность союзного фонтана недоступна, команда отхода не отправляется. Нет автопокупки, стакинга, фарма линий и использования Manta.

Исходные примеры сохранены без изменений; их авторство принадлежит соответствующим авторам.
